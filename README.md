# uav-rf-analytics-platform
# Платформа аналитики радиоэлектронной обстановки (РЭО) и телеметрии БПЛА

Промышленный R&D-проект по сбору, оптимизации и анализу больших массивов телеметрических данных (2 000 000+ логов) для выявления аномалий и фиксации атак РЭБ (поиск 2-й и 3-й гармоник).

## Стек технологий
* **Язык:** Python 3.12.10
* **База данных:** PostgreSQL 16
* **Data Enginerring:** SQLAlchemy 2.0 (ORM), asyncpg (асинхронный драйвер)
* **Data Analytics:** Pandas, NumPy, Jupyter Notebook
* **Визуализация:** Matplotlib, Seaborn

## Архитектура и реализованный функционал
1. **Асинхронный пайплайн загрузки (Data Engineering):** Спроектирована реляционная структура БД с индексацией по ключевым полям. Реализован асинхронный генератор логов с пакетной заливкой (**Batching по 50 000 строк**), что позволило без пиковых нагрузок на ОЗУ залить в PostgreSQL **2 000 000 промышленных записей**.
2. **Математическое ядро (DSP/Аналитика):** Написан алгоритм `detect_harmonic_interference` для автоматического вычисления отклонений частот, базовых сигналов, шумов и выявления потенциальных атак РЭБ по 2-й и 3-й гармоникам.
3. **Оптимизация памяти в Pandas:** Обработка датасета оптимизирована с помощью каста тяжелых типов данных в легкие NumPy-эквиваленты (`float32`, `int8`), что **снизило потребление ОЗУ датафреймом на 70%** и позволило крутить весь массив локально.
